# Trellis

Trellis routes requests to open inference models through an OpenAI-compatible API. It supports USDC payments on Solana and signed receipts for model calls. The local launcher serves the dashboard and a catalog of mock providers.

## Local development

Install Bun and pnpm, then run `bun install --frozen-lockfile` and `bun run launch`. Open the localhost address printed by the launcher.
